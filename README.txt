SKYCAST WEATHER APP

1. Open index.html in a browser to test city search and live weather.
2. For GPS location, host the folder on HTTPS (for example Netlify/GitHub Pages), then allow Location permission.
3. The app uses Open-Meteo's live forecast and geocoding APIs. No API key is required for non-commercial use.
4. To install as an app, open the HTTPS site in Chrome and choose Add to Home screen.
